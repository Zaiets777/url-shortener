# Інженерний щоденник (TECH.md) — URL Shortener

## Обраний технологічний стек та обґрунтування ("Чому?")

### 1. Frontend
- **React + Vite:** Обрано через високу швидкість збірки, зручну компонентну архітектуру та величезну екосистему для швидкої розробки інтерфейсів.
- **React Router:** Стандартний інструмент для реалізації маршрутизації (публічні та приватні сторінки).
- **Tailwind CSS / CSS Modules:** Для швидкої і зручної адаптивної верстки під різні екрани (від мобільних до десктопів).

### 2. Backend
- **Node.js + Express.js:** Легковаговий та популярний фреймворк для побудови швидкого REST API.
- **База даних (MongoDB або PostgreSQL):** Використовується для надійного зберігання облікових записів користувачів та зв'язків із їхніми короткими посиланнями.
- **Bcrypt + JWT / HTTP-only Cookies:** Для безпечного шифрування паролів та керування сесіями авторизованих користувачів.

### 3. DevOps, QA та Деплой
- **Vercel / Netlify:** Для швидкого та безкоштовного розгортання клієнтської частини.
- **Render / Railway:** Для хостингу серверної частини та бази даних.
- **Jest / Supertest:** Для написання автоматичних тестів на бекенді (покриття коду не менше 70%).
- **Swagger (OpenAPI):** Для генерації та зручної документації API.
