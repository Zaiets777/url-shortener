# URL Shortener

Вебсервіс для перетворення довгих URL-адрес у короткі, управління терміном їхньої дії та відстеження детальної статистики переходів у реальному часі.

## 👥 Команда

- **Владислав Клопотенко** — Backend Developer, Database Engineer, DevOps & QA

## 🛠 Tech stack
- **Frontend:** React + Vite, React Router, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB / PostgreSQL
- **Tools:** Git, GitHub Projects, Swagger, Jest

## 💡 Примітки щодо розробки
- Репозиторій зроблено публічним (`Public`), оскільки на безкоштовному тарифному плані GitHub функція захисту гілки `main` (`Branch Protection`) доступна для налаштування саме в публічних репозиторіях.
