# 🔗 URL Shortener - Frontend

Сучасний та швидкий інтерфейс для сервісу скорочення посилань. Дозволяє користувачам легко створювати короткі лінки, керувати ними у своєму воркспейсі та відстежувати детальну статистику переходів.

## 🚀 Технології

* **Фреймворк:** React (Vite)
* **Стилізація:** Tailwind CSS
* **Графіки:** Recharts
* **Маршрутизація:** React Router

## 📊 Основні функції

* **Дашборд:** Перегляд загальної кількості посилань та кліків.
* **Створення посилань:** Швидка генерація коротких URL з можливістю кастомного імені (short.ly/custom-name).
* **Аналітика:** Детальний лінійний графік статистики кліків по днях (інтерактивний тултіп, історія за останні 7 днів).
* **Керування:** Копіювання, перегляд статусу (Active/Expired) та видалення посилань.
